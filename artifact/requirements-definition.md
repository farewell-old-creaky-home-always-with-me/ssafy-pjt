## 기능 요구사항

### 주택 거래 정보 (HOUSE)

| ID | 분류 | 요구사항 | 설명 | 우선순위 | 관련 화면 | 관련 API | 상태 |
|----|------|---------|------|----------|-----------|----------|------|
| REQ-HOUSE-001 | 데이터 수집 | 주택 거래 데이터 수집 | 관리자 API가 `houseDealCollectJob`을 실행하고, Spring Batch가 국토교통부 API 데이터를 수집·정규화·저장한다 | 필수 | 없음 (배치) | POST /api/admin/batch/house-deals | 완료 |
| REQ-HOUSE-002 | 검색 | 주택 거래 검색 | 시도·시군구·읍면동 코드 조건으로 거래 목록 조회 | 필수 | 주택 검색 결과 페이지 | GET /api/houses | 완료 |
| REQ-HOUSE-003 | 상세 조회 | 주택 상세 조회 | 거래 이력, 위치, 면적, 층, 건축연도 등 상세 정보 조회 | 필수 | 매물 상세 페이지 | GET /api/houses/{houseId} | 완료 |
| REQ-HOUSE-004 | 검색 | 거래 유형 필터 | 매매·전세·월세 유형별 필터링 | 추가 | 주택 검색 결과 페이지 | GET /api/houses | 완료 |
| REQ-HOUSE-005 | 검색 | 거래 금액 범위 필터 | 최소·최대 거래금액 범위 필터링 | 추가 | 주택 검색 결과 페이지 | GET /api/houses | 완료 |
| REQ-HOUSE-006 | 데이터 관리 | 주택 기본 정보 관리 | 실거래가 데이터에서 주택 기본 정보를 추출하여 주택별 식별 정보, 법정동, 지번, 건축연도, 이미지 정보를 관리한다 | 필수 | 없음 (DB/관리) | — | 완료 |
| REQ-HOUSE-007 | 지도 | 지도 기반 실거래가 표시 | 지도에서 선택한 주택 또는 아파트의 상세 거래 정보를 조회하여 화면에 표시한다 | 필수 | 메인 페이지, 매물 상세 페이지 | GET /api/houses/{houseId} | 완료 |
| REQ-HOUSE-008 | 검색 | 상세 검색 조건 제공 | 법정동, 아파트명, 주택 유형, 거래 유형 등 사용자가 지정한 조건으로 실거래가를 검색한다 | 필수 | 주택 검색 페이지 | GET /api/houses | 완료 |

주택 거래 데이터 수집은 일반 요청-응답 Service 로직이 아니라 Spring Batch Job으로 처리한다. 관리자 API는 Job 실행과 상태 확인의 진입점 역할만 담당한다.
