# 가중치 기반 매물 추천 알고리즘

- 상태: 구현
- 마지막 수정일: 2026-06-25
- 관련 요구사항: REQ-ROUTE-002
- 적용 화면: 매물 검색 화면
- 적용 API: `GET /api/houses`

---

## 기능명

검색 결과 추천순 정렬

---

## 알고리즘 개요

검색 조건을 만족하는 매물 목록에 대해 가격 적합도, 면적, 거래 최신성, 층수, 건축연도를 점수화한 뒤 총점 기준으로 정렬한다.

```text
recommendScore =
  priceFitScore
+ areaScore
+ recencyScore
+ floorScore
+ buildYearScore
```

---

## 적용 이유

매물 검색 결과는 같은 지역 안에서도 가격, 면적, 거래 시점, 주거 조건이 서로 다르다. 단일 정렬 기준만으로는 사용자가 비교하기 어렵기 때문에 여러 기준을 하나의 점수로 합산해 우선순위를 제공한다.

---

## 점수 항목

| 항목 | 설명 |
|------|------|
| 가격 적합도 | 최소/최대 금액이 있으면 예산 중앙값에 가까울수록 높은 점수 |
| 면적 | 전용면적이 클수록 높은 점수 |
| 거래 최신성 | 최근 거래일수록 높은 점수 |
| 층수 | 높은 층일수록 소폭 가산 |
| 건축연도 | 신축에 가까울수록 높은 점수 |

---

## A*와의 구분

A*는 두 지점 사이의 최적 경로 탐색에 사용된다. 이 추천 알고리즘은 검색 결과 안에서 매물의 우선순위를 계산한다. 두 알고리즘은 서로 다른 사용자 문제를 해결한다.

---

## 한계 및 향후 개선 방향

현재 버전은 별도의 개인 선호 데이터를 저장하지 않고 검색 조건과 최신 거래 데이터만 사용한다. 향후 관심지역, 즐겨찾기, 사용자의 조회 이력을 반영하면 개인화 추천으로 확장할 수 있다.
